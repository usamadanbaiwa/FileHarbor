# Scope and roadmap

FileHarbor provides authenticated uploads, folders, listings, exact-path deletion, account/key management, and a small administrator panel. Images, PDFs, and MP4 videos use a configurable allowlist and a 25 MiB default limit.

The applications are distributed and tested independently. Their normal HTTP behavior follows the root API specification.

Possible future additions:

- Bulk server migration and transfer verification.
- Resumable uploads.
- Private downloads and expiring signed URLs.
- Image/video transformations.
- Storage quotas and additional storage backends.
- Versioning, webhooks, and optional malware scanning.
